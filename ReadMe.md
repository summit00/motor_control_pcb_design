# STM32H563 BLDC Motor Controller

A three-phase BLDC/PMSM motor controller designed for high-performance Field-Oriented Control (FOC).

## Features

- STM32H563 microcontroller
- DRV8353 three-phase gate driver
- Three low-side current shunts
- Up to 60 V DC bus
- CAN interface
- USB-C interface
- Incremental encoder interface
